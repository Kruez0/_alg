## My Understanding of the Problem

A problem to know wether it is possible or not to design universal algroithm that can determine wether any program will run forever or will it eventually halt and finish its execution.
Alan Turing said that this so called problem is unsolvable. Let's assume that there is a program called "H" that IS ALWAYS CORRECT and can determine wether a program halts or not. H will takes another program as input and then it will tells us wether the program will halts or will it run forever. Then, let's make another program called "D", D is programmed to do the opposite of H. For example, if H said the program will halt, D will says it will run forever, or if H said the program will continue forever, D will says that the program will halt. 
The problem starts when D is the program that H is determining. H says that D will halts, but D's job is to do the opposite of what H said, so it will run forever. This means H is wrong but we assumed that H will always be right. This is the halting problem and why it is said that it is the unsolvable problem.

## Conclusion of the Problem
How the problem works:
1. Have a program caled H that determines wether a program halts or not and this program will always be right.
2. Have a program called D that does the opposite of H.
3. Problem occurs when H is programmed to determine D.
4. H said D will run forever.
5. D did the opposite of H because it is how it was programmed.
6. This means H is wrong but H is supposed to be always right.

In conclusion, there is no a universal program that can determines wether any given program will halt or run forever.
